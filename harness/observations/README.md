# Observations

Real problems spotted in passing that are out of scope for the current work and
not yet understood well enough to become a stage.

- [`open.md`](open.md) — live list.
- [`resolved.md`](resolved.md) — promoted, fixed or dismissed, with the outcome.

Entry format:

```markdown
### O-NN — One-line summary
**Spotted:** YYYY-MM-DD, stage N.N
**Why it matters:** the consequence, concretely.
**Not doing yet because:** scope, or unknowns.
```
