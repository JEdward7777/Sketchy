# 0018 — The cycles setting defaults to 2

- **Date:** 2026-11-23
- **Status:** accepted; reinterpreted by 0020 (cycles now set a round count)
- **Stage:** 0.8.9

## Decision
The settings panel's cycles control defaults to **2** (range 1–3, §7),
independent of the timer preset.

## Why
The owner's ruling (2026-11-23): "default with 2 so the host can reduce or
increase it" — the middle value leaves room both ways.

## Rejected
- Default 1 (the recommendation): shortest first game.
- Coupling the default to the timer preset.

## Revisit if
Playtests find the default game too long.
