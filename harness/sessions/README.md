# Sessions

One file per working session, named `YYYY-MM-DD-NN.md` where `NN` increments
within a day. **Immutable once written.**

The newest file is the second thing a new thread reads, after `../STATE.md`. Be
honest about dead ends and half-finished work — they are the part the code
cannot reconstruct.

## Template

```markdown
# YYYY-MM-DD-NN

**Stages touched:** 1.2, 1.3.1
**Left at:** one line — the exact next action.

## What was done
## What was learned
## Half-finished
## Next
## Loose ends not worth a stage
```
